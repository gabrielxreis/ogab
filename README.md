# O Gab (/ogab)

O editor de vídeo com IA que trabalha dentro do Claude Code.

**A instalação é feita pelo painel em [ogab.io](https://ogab.io)**, com a sua key de acesso:
entre em https://ogab.io/login, copie a mensagem pronta de instalação e cole no Claude Code.

Este repositório não contém o Gab. Ele existe só para que links antigos de instalação continuem funcionando:
eles agora chamam o instalador oficial do ogab.io.
